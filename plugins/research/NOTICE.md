# Attribution and design provenance

AI Paper Search is an independent integration for personal, non-commercial
research. Its design was informed by the following public projects:

- Microsoft ResearchStudio `paper_search` (MIT), inspected at commit
  `a785e3aca7a2f0cb9775d45a7f2b5d3bf16f076a`.
- `arxiv-mcp-server` by Joseph Blazick (Apache-2.0), runtime version `0.7.1`.
- ARS-Codex / Academic Research Skills (CC-BY-NC-4.0), workflow concepts only.

This repository does not vendor ARS-Codex content. It includes its own concise
research workflow and invokes the published arXiv MCP package as a pinned
runtime component. See the linked upstream repositories in the README.
